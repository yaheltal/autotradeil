# Mobile assets

Drop the production binaries here before the first `expo start`:

| File                | Purpose                          | Required size                      |
| ------------------- | -------------------------------- | ---------------------------------- |
| `icon.png`          | App icon (square)                | 1024×1024                          |
| `splash.png`        | Splash screen image              | 1284×2778 (iPhone 14 Pro Max safe) |
| `adaptive-icon.png` | Android adaptive icon foreground | 1024×1024                          |
| `favicon.png`       | Web build favicon                | 48×48                              |

The colors / branding referenced from `app.json`:

- background `#0B1F33` (brand navy)
- accent `#D4A437` (brand gold)
